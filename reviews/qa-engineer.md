## Blocking (must fix)
- [B1] `sw.js` `photoList()` / `tools/build_data_js.py`: **zero player photos are precached.** Inside the worker `importScripts('./data/players.js')` throws `ReferenceError: window is not defined` (players.js does `window.PLAYERS_DATA = …`; workers have no `window`). The `try/catch` swallows it, so `photoList()` returns `[]` and the install cache holds only the 7 shell URLs (`caches.open('nora-usopen-v1')` → 7 entries, 0 `img/players/*`). Verified by evaluating in the SW context: `typeof window === 'undefined'`, `importScripts` → ReferenceError, `photoList().length === 0`. Photos are only cached after being viewed online (runtime cache-first), so a cold offline open at the stadium has no photos beyond whatever was scrolled past. → In `build_data_js.py` emit `self.PLAYERS_DATA = …` (`self` is `window` on the page, the worker global in the SW; app.js keeps reading `window.PLAYERS_DATA` unchanged) **or** add `self.window = self;` in `sw.js` before `importScripts`. Bump `VERSION` to `nora-usopen-v2` so existing installs re-precache. Re-verify with `caches.open(...).keys()` → expect 7 + 32 entries.
- [B2] `scripts/app.js` `route()`/`requestClose()`: **closing a deep-linked card navigates off the site.** `route()` sets `cameFromHere = true` on any `#p/` hash, including the initial page load, so `requestClose()` calls `history.back()` whenever `history.length > 1`. Repro: load `http://localhost:8765/` then `…/us-open-kids-guide/#p/coco-gauff`, tap ✕ → URL becomes `http://localhost:8765/` (left the guide). Escape and the Back button do the same. Any shared `#p/<slug>` link opened in a tab that has prior history hits this. → Only set `cameFromHere = true` in the in-page click handler (right before `location.hash = '#p/…'`), never in `route()`; or push with `history.pushState({app:1}, '', '#p/'+slug)` and in `requestClose()` call `history.back()` only when `history.state && history.state.app`, else `replaceState` + `closeDetail()`.
